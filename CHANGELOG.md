## [0.1.0] - 2026-07-25

### Added

- Deterministic seeded runs and financial-centre assignment.
- Immutable game engine with explicit decision, resolution, and liquidation states.
- Five-resource system with immediate, clamped consequences.
- Fixed difficulty progression and weighted, duplicate-free question selection.
- Fifteen-second decisions with deterministic timeout penalties.
- Post-run statistics, competency percentages, resource history, and prestige ranks.
- Mobile-first terminal interface with touch, mouse, and 1–4 keyboard input.
- One hundred original finance scenarios across ten competency families.
- Question schema validation and contributor documentation.
- Automated tests, CI checks, and GitHub Pages deployment workflow.
- Public community, conduct, security, and contribution documentation.

### Known limitations

- The initial release contains one English-language question pack.
- Runs have no persistence, daily seed, or shareable seed link.
- Browser-level assistive-technology coverage is limited and needs community feedback.
- Balancing is an initial release calibration and may change without changing mechanics.
