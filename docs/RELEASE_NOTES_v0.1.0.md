# Fund Manager Tuesday v0.1.0

The first public release delivers a complete, deterministic, mobile-first investment-management game.

## Included

- Seeded, reproducible runs with 15 atmospheric financial centres.
- Five persistent resources and immediate decision consequences.
- Fifteen-second decisions with deterministic timeout behavior.
- Fixed difficulty progression and weighted duplicate-free question ordering.
- One hundred original scenarios across ten finance competency families.
- Venture-capital settings integrated throughout the broader investment curriculum.
- Mobile and desktop terminal-style interface.
- Touch, mouse, and keyboard play.
- Post-run statistics, competency percentages, final resources, and prestige rank.
- Static GitHub Pages deployment with no backend, accounts, tracking, or external APIs.
- Automated engine, content, configuration, and UI integration tests.

## Known limitations

- English only.
- One bundled content pack.
- No saved run history or preferences.
- No daily or shareable seed interface.
- Accessibility has automated and browser-level coverage but still needs broader assistive-technology feedback.
- Initial resource and rank balancing may be refined through playtesting.

## Roadmap

The next release work focuses on balancing evidence, accessibility feedback, content review, and contributor experience. Future content milestones are 300, 700–1,000, and eventually about 1,500 original questions.

Excluded mechanics remain excluded: multiplayer, accounts, leaderboards, progression systems, achievements, live market data, audio, analytics, and monetisation.
