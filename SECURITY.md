# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| Earlier | No        |

## Reporting a vulnerability

Please use GitHub’s private vulnerability reporting feature for this repository. Do not open a public issue or discussion containing exploit details.

Include:

- the affected version;
- reproduction steps;
- potential impact;
- any suggested mitigation.

Maintainers should acknowledge a report within seven days and provide a status update after initial triage. Timelines for a fix depend on severity and complexity.

The project is a static client-side application with no accounts, backend, analytics, or personal-data collection. Security reports about third-party hosting platforms should be directed to the relevant provider unless the project configuration creates the issue.
